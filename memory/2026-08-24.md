## Simulation Hub crash fix + Counter-Trend macro regime + Pitchbook/Spreadsheet upgrades

### Bug Fix: MarketSimulationEngine `universe_size` TypeError
- `__init__` only accepted `date_str` but `_render_comprehensive_sim_tab` called it
  with `universe_size=` and `simulation_duration=` kwargs
- Updated `__init__` signature to accept optional `universe_size: int` and
  `simulation_duration: int` (converts min → timedelta)
- Cleaned up the calling code in `simulation_viewer.py`

### Bug Fix: Counter-trend macro regime always "Unknown / Transition"
- `_fetch_ct_macro_state()` used bare `get_stock()` for futures symbols
  (GC=F, CL=F, DX-Y.NYB) which silently failed.
- Replaced with `get_vix()` for VIX, `get_futures_proxy()` (ETF fallback) for
  gold/oil, and `_safe_fetch()` helper with proxy fallbacks (DX-Y.NYB→UUP,
  ^GSPC→SPY)
- Each fetch individually wrapped so one missing ticker never blocks the pass.

### Pitchbook upgrades (`presentation_generator.py`)
- **Tornado chart** (`_add_tornado_chart`) — stacked horizontal bars showing
  DCF sensitivity: WACC, terminal growth, revenue growth, EBIT margin
- **Football field** (`_add_football_field`) — horizontal bar ranges for DCF,
  scenario range, trading comps, 52-week range (stacked-invisible-spacer technique)
- **Custom branding** (`InstitutionalPresentationGenerator` class now has:
  `firm_name`, `primary_color`, `secondary_color`, `logo_path`,
  `cover_subtitle`, `include_disclaimer`, `font_name`)
- All slide builders (`_build_dcf/mna/lbo/ipo/comps/precedents_pitchbook`)
  accept optional `branding` dict that flows through to cover/footer/disclaimer
- Cover slide renders optional logo and custom color scheme

### Spreadsheet upgrades (`spreadsheet_generator.py`)
- **DCF Model rebuilt with live Excel formulas** — openpyxl writes actual
  cross-sheet references (`=Assumptions!B9`, `=DCF!B15*(1+Assumptions!B10)/...`),
  not static values.  Three sheets:
  1. Assumptions (12 inputs with live formatting)
  2. DCF Model (revenue growth → EBIT → NOPAT → UFCF → PV → TV → equity bridge)
  3. Sensitivity (7×6 WACC×TGR matrix with live `=DCF!` formula references)
  Change any assumption in Excel and every cell recalculates instantly.
- IB styling maintained throughout: navy headers, thick bottom borders,
  accounting number formats, auto-fitted columns, hidden gridlines.

## Dark Pool lazy tabs + strategy engine + UI fixes

Picked up uncommitted changes from previous session and got them across the line:

### Dark Pool UI: lazy tab rendering
- Replaced `st.tabs` (renders all 15 tabs on mount) with `st.selectbox` + if/elif chain
- **Bug caught:** `st.selectbox` returns the selected string value, but comparisons
  used integers (`active_idx == 0`, etc.) — so NO tab content ever rendered.
  Fixed by converting the return value: `active_idx = _DP_TAB_NAMES.index(active_idx)`
- Tab selection persists in `st.session_state["dp_active_tab"]`

### Strategy Intelligence: dynamic keyword-driven suggestions
- `suggest_strategies()` now parses user goals text for keywords (income, growth,
  momentum, mean-reversion, macro, sector, options, hedging, etc.)
- Matches against an 11-strategy catalog with risk-tolerance-adjusted Sharpe ratios
- Falls back to risk-profile-appropriate strategies when no keywords match
- Replaces old hardcoded 2-per-tier approach

### Daily Briefing: empty-state messages
- Shows fallback messages when risks/opportunities are empty
- Adds regime_desc fallback when market data unavailable

### Crowding table fix
- Displays `crowding_adjusted_signal` instead of `avg_zscore` in the Quant Modeling Lab
