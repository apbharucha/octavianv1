## Bug Fix: Paper Trading UI TypeError

### Error
```TypeError: 'NoneType'object cannot be interpreted as an integer
File "paper_trading_ui.py", line 401, in show_automation_controls
disabled=status and status['is_running']
```
### Root Cause
Button `disabled`parameter was receiving None values when:
- `status`dict was None
- `status['is_running']`was None
- Boolean expressions with None evaluated incorrectly

Streamlit's button widget expects a proper boolean (True/False), not None or complex expressions that might evaluate to None.

### Fix
**File:** `paper_trading_ui.py`(lines 395-430)

Changed from:
```python
disabled=status and status['is_running'] # Could be None
disabled=not status or not status['is_running'] # Complex expression
```
To:
```python
# Safely extract and convert to proper booleans
is_running = bool(status and status.get('is_running', False))
is_paused = bool(status and status.get('is_paused', False))
is_stopped = not status or status.get('status') == 'STOPPED'
# Use clean boolean variables
disabled=is_running
disabled=not is_running or is_paused
disabled=not is_paused
disabled=is_stopped
```
**Benefits:**
- Explicit boolean conversion with `bool()`- Safe dictionary access with `.get()`and defaults
- Clear variable names for readability
- No None values passed to Streamlit widgets
- Proper handling of missing status data

## Major Enhancement: Dynamic Intent Detection Engine

### User Request
Create a heavily intensive dynamic intent detection model that deciphers intent and prompt needs, then formulates how the chatbot answers and displays responses based on detected intent.

### Implementation
**New File:** `intent_detection_engine.py`(~700 lines)

**Architecture: Multi-Layered Intent Analysis**

**1. Intent Categories (14 types)**
- Price Query, Prediction, Risk Analysis, Technical Analysis
- Fundamental Analysis, News Sentiment, Comparison, Sector Analysis

**2. Response Formats (7 types)**

**3. Detail Levels (4 types)**
- Quick (1-2 sentences)

- Deep (comprehensive deep dive)
- Expert (professional-level detail)

**4. Urgency Detection (5 levels)**
- Immediate (right now, urgent)
- Today (within trading day)
- Short-term (days to weeks)
- Medium-term (weeks to months)
- Long-term (months to years)

**5. Advanced Analysis Features**
- Pattern matching with confidence weights (0.0-1.0)

Calculates how ambiguous a query is based on intent score distribution.
High ambiguity = multiple intents with similar scores.

**8. Confidence Scoring**
Measures how confident the system is about the detected intent.
