# 2026-08-17 (session 2) — LLM research-integrity upgrade + extreme stress test

## Task
User attached the flawed NVDA institutional memo output + a full 20-section
"INSTITUTIONAL FINANCIAL ANALYSIS ENGINE — RESEARCH INTEGRITY UPGRADE" spec
and asked to (a) tweak the LLM accordingly, (b) run an extreme stress test.

## What was wrong with the old memo (_build_institutional_deep_dive)
- Arbitrary confidence (88/72/58/68) despite missing critical data.
- "Real DCF" was really a 3-line framing, no mechanics; benchmark return
  spanned the wrong window; no reverse-DCF grid.
- Generic macro text; sentiment inferred from the 5-day tape; no Bayesian,
  no information advantage, no Monte Carlo, no real falsification, no QC.
- No data-completeness gate; no per-segment reconstruction.

## What was built (financial_llm_engine.py, +982/−250)
Full spec implementation as deterministic helpers + assembler:
1. **Provenance legend** — every number tagged OBSERVED DATA / REPORTED
   FINANCIAL DATA / CONSENSUS ESTIMATE / MARKET-IMPLIED VALUE / MODEL
   CALCULATION / MODEL ASSUMPTION / HISTORICAL STATISTIC / SCENARIO
   ASSUMPTION / INFERENCE. Missing data prints exactly
   "DATA UNAVAILABLE - NO ESTIMATE SUBSTITUTED."
2. **Data completeness gate** (section 2) — availability matrix (price,
   fundamentals, balance sheet, cash flow, segments, consensus, options,
   short interest, 13F, macro, news) + completeness score that DRIVES
   confidence. Quote-only memos score ~18%, fundamentals ~36%.
3. **Fundamental reconstruction** — NVIDIA segment framework (Data Center/
   Gaming/ProViz/Automotive/OEM) + 3b quantified sensitivity table
   (gross-margin bps → EPS%, operating leverage, ASP/unit mix, capex, tax).
4. **AI infrastructure economics** (mandatory; "not applicable" variant for
   non-AI names) — capex→ROI chain, cycle classification with probabilities
   (secular 45 / supercycle 25 / bubble 10 / mixture 20), slow-down triggers.
5. **Competitive moat matrix** — NVIDIA/AMD/Custom ASIC/Hyperscaler across
   9 factors + share-loss sensitivity 0/5/10/15/20/30% vs tolerance.
6. **Real DCF engine** — Bear/Base/Bull with full mechanics (revenue→EBIT→
   NOPAT→FCF→PV→terminal→EV→equity→per share), WACC×g sensitivity grid,
   and an explicit DCF-vs-market reconciliation (conservative DCF anchor
   sits far below market price = the quantified expectation gap).
7. **Reverse DCF grid** — WACC × FCF-yield → implied growth; what must
   happen operationally.
8. **Expectation-gap engine** — company/consensus/model/market-implied.
9. **Macro transmission table** — per variable: earnings impact × multiple
   impact = total; 5 regime scenarios.
10. **Sentiment engine** — positioning NEVER inferred from price momentum;
    retail/13F/sell-side/options/short-interest all DATA UNAVAILABLE.
11. **Risk engine** — full matrix with leading indicator, mitigation,
    priced-in?, plus non-consensus risks (AI-capex digestion, concentration).
12. **Catalyst engine** — Known/Probable/Speculative × timeline buckets, no
    fabricated dates.
13. **Five-scenario engine** — full table (prob/revenue/growth/margin/EPS/
    FCF/exit multiple/price/return), probabilities sum EXACTLY 100%.
14. **Monte Carlo** — empirical CDF of scenario set, P10–P90 (monotonic),
    >10/20/30/50% loss probs, P(outperform SPX).
15. **Bayesian updates** — 10 evidence events with LR vectors, posteriors
    renormalized to 100%.
16. **Information advantage** — 8 variables (GPU backlog, token economics,
    utilization, power pipeline, hyperscaler ROI, ASIC wins, concentration,
    China licenses) with measurement/proxy/bullish/bearish/availability.
17. **Falsification** — 10 ranked arguments, confirm/falsify per argument,
    thesis-threatening/weakening/noise, single rating-reverser.
18. **Confidence engine** — computed from completeness + fundamentals
    availability + scenario dispersion; <70% always (honest).
19. **Final committee output** — rating, fair value, 12m/24m returns,
    drawdown probs, 5 reasons for/against, 5 key variables, biggest
    disagreement/risk/catalyst, what changes rating.
20. **QC audit** — programmatic internal-consistency checklist with
    AUDIT PASS / ANALYSIS INCOMPLETE verdict.
Plus: entity firewall defense-in-depth (financial-metric tokens never become
subjects — _is_financial_metric_token), fundamentals fetch via
fetch_ticker_fundamentals (REPORTED data; offline-guarded by OCTAVIAN_OFFLINE),
and a RESEARCH-INTEGRITY RULES block added to the LLM system prompt.

## Key design decisions
- `_build_institutional_deep_dive(..., fundamentals=None)` — optional
  dict param for tests; None → live fetch (offline env → {}).
- Deterministic: no randomness; same inputs → byte-identical output.
- Section 4 always present ("not applicable" for non-AI names).
- DCF fair values are CONSERVATIVE anchors far below market price — the
  reconciliation note explains the gap explicitly rather than hiding it.

## Stress test (tests/test_deep_dive_integrity.py, 43 tests)
All 20 sections present/in-order both paths; provenance tags; no fabricated
numbers (DATA UNAVAILABLE markers); confidence <70% & rises with fundamentals;
firewall (DCF/FCF/EBITDA never subjects); data-gate scoring; DCF mechanics
recomputed independently (1e-6 match); reverse-DCF grid; expectation gap;
macro transmission; sentiment honesty; risk/catalyst tables; scenario probs
sum to exactly 100; MC percentiles monotonic; Bayesian posteriors sum to 100
(10 rows); 10 falsification arguments; QC verdict both paths; determinism;
bear tape lowers rating; deep-dive routing; system prompt carries rules;
6-query fuzz matrix; empty-live-data path.

## Verification
678 passed / 0 failed across two full runs (635 + 43 new), boot HTTP 200,
pyflakes clean of new issues. Real network memo: NVDA $225, fundamentals
fetched, DCF computed, overall confidence 54% (honest).

## Lesson
When "tweaking the LLM" for a rule-based engine, the spec text IS the
requirements doc — implement every numbered section as deterministic,
auditable code with explicit provenance on every number, and make confidence
a computed function of data completeness, never an arbitrary constant.
